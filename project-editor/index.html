Using the editor

Open a SQUID Manager .prj export or create a project. Select a track and pattern, then edit each step’s notes, velocity, gate, CC values and transpose automation. Up to eight notes fit in a step.

Use Pattern sets to capture, edit or recall scenes across tracks. Musical settings edits fixed length, swing, probability, scale, modulation and arpeggiator settings. Track harmonizer chords and step ties, chord assignments, speed, roll and Groove Bend have their own controls. Interpolate / randomize previews an edit before applying it; undo restores the previous project.

Pattern sets


Each set stores one pattern and a mute state per track. Choose a set, then edit its entries. Every change is undoable. Recall selects its patterns in the editor and applies its mute states.







The selected member supplies its group's slot; other groups use their first member's selection. Missing patterns remain unassigned. Group controls change all members; expand Individual tracks for overrides.
